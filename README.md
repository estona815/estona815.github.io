# 치이카와 덕력고사 · 덕력 소풍

[공개 사이트](https://estona815.github.io/) · [덕력 노트](https://estona815.github.io/guides/)

공식 공개 자료를 확인해 직접 작성한 한국어 비공식 팬 퀴즈입니다. 40문제 중 난이도별 20문제를 뽑아 풀고, 해설과 개인 성적표를 확인할 수 있습니다. 캐릭터·세계관·입문 가이드 3편도 제공합니다.

## 운영

- 정적 HTML/CSS/JavaScript 사이트. 별도 빌드 없이 GitHub Pages의 `main` 브랜치 루트에서 제공합니다.
- 답안과 성적표는 이용자의 브라우저에만 저장합니다. `내 기록`에서 지울 수 있습니다.
- 성적표 PNG는 브라우저에서 생성합니다.
- 장식은 직접 구성한 꽃·편지·노트·지도 SVG입니다. 원작 이미지나 만화 컷은 포함하지 않습니다.
- `assets/OFL-*.txt`에 글꼴 라이선스가 있습니다.

## AdSense 준비 상태

게시자 `ca-pub-4959050536850164`의 확인용 메타 태그와 `ads.txt`를 제공하고 있습니다. **광고 송출은 비활성**입니다. 사이트 승인, 실제 광고 단위, 동의 관리 검토가 끝나기 전에는 광고 요청을 보내지 않습니다. 광고 위치는 충분한 본문이 있는 가이드 아래로 제한하며, 퀴즈·결과·해설 화면에는 광고를 넣지 않습니다.

`ads-config.json`과 `ads.mjs`의 구현 검토 게이트를 모두 확인해야 활성화할 수 있습니다. 광고 코드가 있다는 것과 Google의 사이트 승인·실제 송출은 별개입니다.
