개인정보·광고 안내

어떤 정보가 어디에 남는지,
지금 실제로 작동하는 방식대로 안내해요.

현재 상태: Google AdSense 게시자 확인용 메타 태그와 ads.txt를 제공하고 있어요. 외부 광고 스크립트와 방문 분석 도구는 활성화하지 않았어요. 이 설정만으로 광고 쿠키가 만들어지거나 광고가 표시되지는 않아요.

1. 퀴즈 이용과 브라우저 저장

회원가입, 이름, 전화번호, 생년월일을 입력하지 않고 이용할 수 있어요. 퀴즈 코드는 답안과 점수를 별도 서버로 전송하지 않아요. 브라우저의 localStorage에 아래 기록을 저장해요.

  • chiikawa-exam-v1: 진행 중인 문항, 보기 순서, 선택한 답, 현재 위치, 저장 시각, 문제은행 버전. 이어 풀기 기능에 사용해요.
  • chiikawa-result-v1: 마지막으로 완료한 시험의 문항·답안·저장 시각. 성적표 다시 보기와 해설에 사용해요.
  • iyiy-coupon-plan-v1: 별도 혜택 운영안 도구를 사용했을 때만 저장하는 초안. 실제 쿠폰 발급이나 판매자 설정에 전달되지 않아요.

새 기록을 저장하거나 직접 삭제하기 전까지 해당 브라우저에 남을 수 있어요. 브라우저가 사이트 데이터를 자동 삭제하면 기록도 사라질 수 있어요. 다른 기기나 브라우저로 자동 이동하지 않아요.

2. 기록을 지우는 방법

퀴즈 하단의 내 기록 → 이 브라우저의 풀이 기록 지우기에서 진행 중인 답안과 최근 성적표를 삭제할 수 있어요. 운영안 초안까지 모두 지우려면 브라우저 설정에서 이 사이트의 저장 데이터 전체를 삭제해 주세요.

저장소 접근이 차단된 환경에서는 앱의 삭제가 실패할 수 있어요. 이 경우 화면 안내에 따라 브라우저 설정에서 삭제해야 해요. 브라우저 기록은 운영자에게 전송되지 않으므로 운영자가 원격으로 찾아 지울 수는 없어요.

3. 성적표 이미지와 공유

성적표 PNG는 이 기기에서 만들어요. 다운로드하면 이용자가 선택한 기기에 파일이 남아요. ‘친구에게 자랑하기’를 누르면 선택한 앱에 점수·등급·시험 주소와 지원되는 경우 이미지를 전달할 수 있어요. 공유를 실행하기 전에는 결과를 외부 소셜 서비스에 자동 게시하지 않아요.

4. 페이지 요청과 운영 환경

페이지·글꼴·그림을 불러올 때 호스팅 제공자에게 IP 주소, 브라우저 정보, 요청 URL 등의 연결 정보가 전달될 수 있어요. 이는 웹페이지 제공과 보안·장애 대응에 사용되는 서버 처리와 관련돼요. 퀴즈에는 별도의 방문 분석 코드나 광고 추적 코드를 활성화하지 않았어요.

주 공개 주소는 GitHub Pages에서, 이전 공유 주소는 ChatGPT Sites에서 제공해요. 호스팅 제공자의 데이터 처리에 관한 내용은 GitHub 개인정보처리방침과 OpenAI 개인정보처리방침을 확인해 주세요. 공식 출처나 외부 링크로 이동하면 해당 서비스의 정책이 적용돼요.

5. Google 광고가 활성화되는 경우

광고 도입 시 Google 및 다른 제3자 광고 제공업체는 이용자의 이 사이트 또는 다른 사이트 방문을 바탕으로 광고를 제공하기 위해 쿠키를 사용할 수 있어요. Google의 광고 쿠키는 Google과 파트너가 이전 방문에 기초한 광고를 제공하는 데 사용될 수 있어요. IP 주소, 기기·브라우저 및 광고 상호작용 정보도 광고 제공·보안·측정에 처리될 수 있어요.

Google 내 광고 센터에서 개인 맞춤 광고 설정을 관리할 수 있어요. Google 파트너 사이트 정보 사용 안내와 참여 광고업체의 선택 해제 안내도 참고할 수 있어요.

비개인 맞춤 광고도 빈도 제한이나 보고를 위해 쿠키를 사용할 수 있어요. 필요한 지역의 동의 절차와 Google이 요구하는 인증된 동의 관리 설정을 마련하기 전에는 광고를 활성화하지 않아요. 실제 광고 제공업체와 이용자가 선택을 변경하는 방법은 활성화 시점에 이 페이지에 반영해요.

6. 문의로 보내는 정보

문의 링크는 이메일 앱을 열어요. 보내기 전에는 사이트가 문의 내용을 자동 제출하지 않아요. 이메일을 보내면 회신 주소와 이용자가 작성한 내용·첨부파일이 운영자 및 이메일 서비스에 전달돼요. 문의 확인·회신·오류 정정·권리 요청 처리에 사용해요.

문항 확인에는 문제 문구와 출처 링크만으로 충분해요. 주민등록번호, 비밀번호, 금융정보처럼 문의 해결에 필요하지 않은 정보는 보내지 말아 주세요. 보낸 문의의 삭제를 원하면 아래 연락처로 해당 메일의 제목과 발송 시점을 알려 주세요.
